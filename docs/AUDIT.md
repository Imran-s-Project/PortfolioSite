# Audit of the original project (`MyProject-main`) and how it was migrated

> This page documents the migration from the original vanilla site. For the later repair pass (ESLint, hydration, Firestore errors, blog editor, footer, tests) see [REPAIR_REPORT.md](REPAIR_REPORT.md).

## What the original contained
Vanilla-JS ES-module site, no build step: `index.html`, `css/styles.css`, `js/` (data, core, sections, features), 6 nature scenes (hero → projects → about → skills → contact → footer) with MP4/WebM + posters + `manifest.json`, CV, OG image, Vercel config. 21.7 MB, of which ~20 MB is footage.

## Findings
**Dead code (never imported by `js/main.js`/`js/app.js`)** — not migrated:
`js/sections/*` (header, hero, heroBanner, showcase, projects, about, contact, footer, modal — an earlier layout that reads fields `projects.js` no longer has) and nine files in `js/features/` (old SVG scene drawing, ember field, typewriter, magnetic, cursor glow …). Their useful ideas (magnetic links, role title animation, showcase video) were re-implemented properly.

**Bugs found in the original**
1. **The "Download CV" link was broken.** `content.js` pointed to `assets/imran-ahmed-cv.pdf`; the file is `assets/imran_ahmed_cv.pdf`. → fixed (`RESUME_URL`).
2. `og:image` / `og:url` were relative (`/assets/og-image.png`, `/`) — social crawlers ignore these. → `metadataBase` + absolute URLs.
3. `og:title` differed from `<title>`; the page title and share title disagreed. → one source per page.
4. The **showcase video** (`…/ad.vd/imran's.mp4`) is not in the repository and the section was never rendered. → kept as an optional section, off until a URL is set in *Admin → Settings*.
5. **X (Twitter) link `https://x.com/imranahmed-bd`**: X handles cannot contain a hyphen, so this is probably wrong. **Kept exactly as supplied** — please verify it.
6. The Bangla footer line was English ("Designed and created by — Imran Ahmed, Love ♥ With"). A Bangla version was added; the English text is unchanged.
7. Stray 1-byte file `tools/H`; a leading space in the name of the last project. → dropped / trimmed.
8. The hero copy says "every line written in vanilla JavaScript and Firebase, no frameworks". That describes the owner's projects and is preserved verbatim — but **this portfolio itself is now a Next.js app**. Review whether you want to reword it.

## What was preserved (verified by tests in `tests/data.test.ts`)
* All **10 projects**, same order, same URLs, same Bangla/English names, categories and descriptions.
* All **7 social links**, the owner's e-mail, profile text (bilingual), skills and their groups, section copy.
* The six cinematic scenes, their config, the videos, posters, manifest and credits; the CV; the engine's behaviour (adaptive tiers, Save-Data, frame-rate guard, visibility pausing, poster/gradient fallbacks, pause/play control, localStorage keys).

## Where things went
| Original | New |
|---|---|
| `js/data/projects.js` | `src/data/legacy/projects.json` → `src/data/seed-projects.ts` (+ admin-editable overrides in Firestore) |
| `js/data/content.js`, `ui.js`, `social.js` | `src/data/legacy/*.json` → `src/data/site-data.ts` (generated by `tools/migrate-legacy-data.mjs`, so the copy is byte-for-byte) |
| `js/data/scenes.js`, `features/sceneManager.js`, `atmosphere.js`, `parallaxEngine.js`, `qualityProfile.js`, `core/ticker.js`, `core/motionPref.js` | `src/data/scenes.ts`, `src/lib/nature/*`, `src/lib/motion-pref.ts` (typed ports, same logic) |
| `js/core/lang.js` (localStorage language) | route-based locale `/bn` `/en` + cookie, `src/i18n/*` |
| `assets/nature/*`, `assets/*.pdf` | `public/nature/*`, `public/assets/*` |
| `css/styles.css` | `src/styles/*` (design tokens, 5 themes) |
| `vercel.json` cache headers | `next.config.ts` |

The original is untouched: do the migration on a branch (`git checkout -b next-migration`), keep `main` as the backup.
